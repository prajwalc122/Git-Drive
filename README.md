# GitDrive

GitDrive is a modern frontend file and project management application inspired by **Google Drive and GitHub**. It provides a clean workspace where users can organize projects, create folders, upload files, preview content, search files, and manage everything from one interface.

## Features

* Create folders and subfolders
* Upload multiple file types
* Drag-and-drop upload
* Search files and folders
* Rename and delete files
* Download files
* Image preview
* Video preview
* PDF preview
* Text and code file viewer
* Grid and list views
* Recent files
* Favorite files
* Storage usage display
* GitHub-style project organization
* Responsive UI for mobile, tablet, and desktop

## Supported Files

GitDrive can manage common file formats such as:

* HTML

## How It Works

GitDrive stores and organizes files directly through the browser in the frontend version. Browser technologies such as **IndexedDB** can be used to store larger files locally on the user's device.

Folders themselves require very little storage. The actual uploaded files such as images, videos, PDFs, and ZIP files consume storage depending on their file size.
